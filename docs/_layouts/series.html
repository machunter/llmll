--- layout: default --- {{ content }} {%- comment -%} Previous/next navigation for the series. The posts are plain pages rather than Jekyll `_posts`, so `page.previous` and `page.next` are not available. `_data/series.yml` carries the reading order and this walks it, matching on the page's own URL. Note the index arithmetic is done with `assign` BEFORE the lookup. Liquid does not accept a filter expression inside index brackets, so `posts[idx | minus: 1]` is not prev-1: it silently yields nothing, which rendered an empty nav on the first try. {%- endcomment -%} {%- assign posts = site.data.series -%} {%- assign here = page.url | remove: site.baseurl -%} {%- assign idx = -1 -%} {%- for p in posts -%} {%- if p.url == here -%}{%- assign idx = forloop.index0 -%}{%- endif -%} {%- endfor -%} {%- if idx >= 0 -%} {%- assign previdx = idx | minus: 1 -%} {%- assign nextidx = idx | plus: 1 -%} {%- assign lastidx = posts.size | minus: 1 -%}
{%- if idx > 0 -%} {%- assign prev = posts[previdx] -%} Previous {{ prev.title }} {%- endif -%}
{%- if idx < lastidx -%} {%- assign next = posts[nextidx] -%} Next {{ next.title }} {%- endif -%}
All five posts
{%- endif -%}
