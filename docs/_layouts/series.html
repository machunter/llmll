--- layout: default --- {{ content }} {%- comment -%} Previous/next navigation for the series. The posts are plain pages rather than Jekyll `_posts`, so `page.previous` and `page.next` are not available. `_data/series.yml` carries the reading order and this walks it, matching on the page's own URL. `forloop.index0` gives the position, so the neighbours are just index-1 and index+1. {%- endcomment -%} {%- assign posts = site.data.series -%} {%- assign here = page.url | remove: site.baseurl -%} {%- assign idx = -1 -%} {%- for p in posts -%} {%- if p.url == here -%}{%- assign idx = forloop.index0 -%}{%- endif -%} {%- endfor -%} {%- if idx >= 0 -%}
{%- if idx > 0 -%} {%- assign prev = posts[idx | minus: 1] -%} Previous {{ prev.title }} {%- endif -%}
